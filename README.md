# Brian's Interests

A small static page about what I do outside of work — built by hand while
practicing HTML and CSS fundamentals.

Live at: https://brian7952002.github.io/personal-interests/

## Notes

- No framework, no build step. Open `index.html` and it runs.
- Artwork in `assets/` is hand-written SVG.
- Layout is a single centered column capped at `65ch` for readable line length.
